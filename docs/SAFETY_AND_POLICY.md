# Safety and Policy

Allowed:
- public web search
- official shelters and found-pet sources
- user-uploaded images
- user-authorized authenticated browser session use

Not allowed:
- bypassing private groups or closed communities
- credential theft or session hijacking
- autonomous contact with third parties
- bulk surveillance use outside the missing-pet case

Implementation rules:
- require explicit toggle for browser-session mode
- redact owner phone numbers from logs unless export is requested
- keep audit trail for every candidate source
- include robots/rate-limit awareness in adapters where applicable
