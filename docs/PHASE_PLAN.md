- local MCP server
- case intake
- sqlite persistence
- public web adapter
- 2-3 found-pet adapters
- simple image embedding pipeline
- explainable ranking
- export bundle

Exit criteria:
- from one case, operator can generate a ranked candidate list and export evidence

## Phase 2 — Better evidence and visuals

- duplicate cluster review
- review console

## Phase 3 — Continuous monitoring
- scheduled crawl runner
- change detection
- daily digest resource
- alert-ready event stream

## Phase 4 — Hardening
- postgres/pgvector option
- adapter retry/backoff
- benchmark dataset
- test fixtures for ranking regression
